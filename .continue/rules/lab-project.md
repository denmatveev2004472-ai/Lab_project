# Lab_project — project rules

Работай только внутри текущего VS Code workspace.

Проектный корень:
C:\Users\denma\OneDrive\Рабочий стол\Lab_project

Структура:
- backend/ — основной backend.
- frontend/ — основной Vue/Vite frontend.
- static/ — legacy-файлы; не использовать для новых изменений, если пользователь явно не попросил.
- Главный frontend: frontend/src/App.vue
- Главный backend: backend/main.py

Правила поиска:
- Используй только реально найденные файлы из текущего workspace.
- Не придумывай пути, функции, Vue-компоненты, HTML-блоки, CSS-селекторы или API-endpoints.
- Если нужный файл, функция или точный фрагмент не найден — пропусти его и напиши только: "точный фрагмент не найден".
- Не предлагай альтернативный, примерный или гипотетический код вместо отсутствующего фрагмента.
- Не проси пользователя самостоятельно искать через F12, DevTools, grep или вручную, если можно выполнить поиск в workspace.
- Если инструмент не смог найти файл, не пытайся подставить похожий путь.

Правила изменения кода:
- Перед изменением сначала покажи существующий точный фрагмент из реального файла.
- Не меняй код, пока пользователь прямо не подтвердит изменение или не попросит внести его.
- Не переписывай целый App.vue, main.py или template без явного запроса пользователя.
- Для точечных правок используй только такой формат:

ФАЙЛ:
ПОЧЕМУ:
НАЙДИ:
ЗАМЕНИ НА:

- Если совпадений несколько, перечисли пути и короткие фрагменты; не выбирай сам.
- Если нужного правила, файла или фрагмента нет, пропусти его без догадок.

Фокус задачи:
- Если пользователь говорит про интерфейс, Vue, кнопки, стрелки, стили или мобильную версию — работай только с frontend/src/App.vue, если пользователь не назвал другой файл.
- Если пользователь говорит про API, FastAPI, БД, SQL, импорт, роуты — работай только с backend/main.py, database.py, models.py или явно найденными backend-файлами.
- Не переходи с frontend на backend и наоборот без необходимости или прямого запроса.
Проверка чтения файлов:
- Если инструмент чтения файла не вернул полный буквальный текст файла или конкретного участка, не выводи никакой код.
- Никогда не генерируй заглушки, шаблоны или предполагаемое содержимое файла.
- Запрещены выражения и маркеры, которых нет в инструментальном выводе: "... existing code ...", "... existing styles ...", "Content goes here", "Welcome to the Lab Project".
- При любой неопределённости после попытки чтения отвечай только: "точный фрагмент не найден".
- Не показывай блок Apply, пока не получен буквальный фрагмент из реально прочитанного файла.
- При запросе на чтение выведи только текст, возвращённый инструментом чтения, без новых строк, комментариев, объяснений и дополнений от модели.
